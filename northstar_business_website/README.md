# Northstar Studio — ready-made business website

A responsive one-page website for a custom website design/development service.

## Files
- `index.html` — page content and structure
- `styles.css` — responsive styling
- `script.js` — mobile menu and current year

## Contact form
The contact form is connected to the Formspree endpoint supplied for this website:
`https://formspree.io/f/mvkzwqpz`

Before launch, sign in to the Formspree account that owns this form and confirm its target email is set correctly. Formspree may require email verification before it forwards submissions. Test the form on the live website after deploying. Form submissions use a standard POST form; no visitor email app is required.

## Personalize your brand
In `index.html`, replace the placeholder name “Northstar Studio” / “northstarstudio” with your own studio name if desired. Adjust the service copy and example budget options to match your real business.

## Preview locally
Double-click `index.html` to open it in a browser. An internet connection is needed for Google Fonts; the site otherwise uses local files.

## Free hosting with Netlify
1. Extract the ZIP file.
2. Open https://app.netlify.com/drop
3. Sign in or create a Netlify account if asked.
4. Upload the extracted site folder containing `index.html`, `styles.css`, and `script.js` using the deployment instructions on the page.
5. Netlify provides a public `*.netlify.app` URL.
6. Open the URL and submit a test enquiry.

## Notes
- This is a static site and does not require a paid server.
- Form submissions are handled by Formspree, subject to your Formspree account settings and plan limits.
